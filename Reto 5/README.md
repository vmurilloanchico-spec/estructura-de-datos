# Reto 5: Fila del cajero

Proyecto React sencillo para practicar una cola FIFO.

## Ejecutar

```bash
npm install
npm run dev
```

Cada persona tiene nombre, monto de retiro y hora de llegada. Al agregarla, la app guarda la fecha y hora automáticamente. La fila aparece ordenada desde quien llegó primero y el botón «Atender siguiente» retira a esa persona.
