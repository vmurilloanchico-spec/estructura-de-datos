# Challenge 02 — Contactos Angular

Aplicación Angular standalone para administrar contactos. Incluye:

- Cargador al iniciar y carga simulada de una lista inicial.
- Crear contactos con nombre y teléfono, con validación de campos.
- Editar y eliminar contactos.
- Componentes separados para formulario, listado y cargador.
- Servicio `ContactService` que centraliza los datos y simula la carga asíncrona.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:4200/`.

Para generar la versión de producción:

```bash
npm run build
```
